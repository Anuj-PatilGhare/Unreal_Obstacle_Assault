
# 🎮 Obstacle Assault | Unreal Engine 5 (C++)

> A 3D obstacle course game built with **Unreal Engine 5** and **C++**, focused on gameplay programming, reusable components, and core Unreal Engine development concepts.

---

## 📖 Project Overview

**Obstacle Assault** is a 3D platformer where the player must navigate through a series of challenging obstacles, including moving platforms and rotating hazards, to reach the finish line. This project was developed to strengthen my understanding of Unreal Engine's Gameplay Framework, C++, and real-time game mechanics.

Throughout this project, I explored how to build interactive gameplay systems, write modular and reusable code, and apply industry-standard game development practices.

---

# 📂 Repository Information

> **Why are only the source files included?**

To keep this repository lightweight and easy to browse, **only the project scripts and source files have been uploaded to GitHub**.

The original Unreal Engine project contains **approximately 3.5 GB of assets**, including models, textures, materials, and other content files, which would make the repository unnecessarily large.

For anyone who would like to explore or run the complete project, I have uploaded the full Unreal Engine project separately.

The environment includes:

* 🏞️ Detailed landscape and environment assets
* 🧱 Platforms and structural elements
* 🌿 Decorative props and environmental objects
* 💡 Dynamic lighting for improved visual quality
* 🎨 Materials and textures to enhance the overall scene

The level was designed to provide a smooth progression in difficulty while encouraging exploration and precise movement.
